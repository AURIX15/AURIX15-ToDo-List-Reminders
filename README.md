# AURIX15 To-Do List Reminders

A mobile-friendly installable task manager with a black, gold and silver theme.

## Features
- English and Arabic interface
- Tasks stored locally and separately on each device
- Due dates, priority levels and reminder lead times
- Browser notifications when permission is granted
- Offline app shell through a service worker

## Reminder limitation
This version checks reminders while the app is open or active. Browser notification permission does not guarantee scheduled delivery after the app/browser is fully closed. Reliable closed-app push reminders require a push service and a trusted server-side scheduler. No private server credentials are stored in this repository.

## Deploy
Review and test the feature branch before merging it into main and enabling GitHub Pages.
